# Pyxis

A launcher app with mini-apps inside. Think of it as a productivity toolbox that brings together small, useful applications in one place.

## About

Pyxis is an open source desktop application built with Dear PyGui that acts as a launcher for various mini-applications. It features Supabase authentication (Google and email/password login) and allows official apps to use Supabase's database for features like notes, tasks, and more.

The app is designed to be extensible - you can add your own mini-applications and translate it into different languages.
